Export standard: 1920×1080, 30 fps, no live narration, stable opening and closing holds, no fade to black, and browser-compatible H.264 video with AAC audio. Confirm each export in the target presentation browser.

Working `.mov` recordings belong in the edit/source workflow. The offline package script includes only the eight named final MP4s and never packages source recordings.

The package builder can create a clearly labeled draft while exports are missing. It creates the final `WGW_R4_Demo_Offline_v1.zip` only after all eight files are present.
